# 期权 101

> 从零开始到第一笔交易

一本写给"有股票经验、但没做过期权"的人的入门小册子，与《期货 101》同一套编纂方式：一章一个 Markdown 文件，先写成书稿，再打包 EPUB。

作者：大马

## 结构

```
封面 → 目录 → 知识点清单 → 正文（五部分）
```

| 部分 | 内容 |
|---|---|
| 第一部分 基础知识 | 期权是什么、买方与卖方、合约要素、T 型报价、权利金构成、国内期权地图 |
| 第二部分 交易 | 开户与权限、下单与行权、到期日、买方仓位、卖方保证金、成本、行权交收、美国市场对比 |
| 第三部分 深入理解 | 定价直觉、希腊字母、时间价值、隐含波动率、买卖方胜率、亏损机制 |
| 第四部分 案例解析 | 2015 上市首课、2020 波动率爆炸、2024 隐波飙升、末日轮、卖方爆仓 |
| 第五部分 一次交易 | 五问 → 选合约 → 设观点 → 算三个数 → 定仓位 → 定离场 → 下单 → 复盘 |

## 文件

- `OUTLINE.md` —— 详细大纲与写作原则
- `mds/` —— 书稿（一章一个 Markdown 文件）
- `tools/build_epub.py` —— EPUB 构建脚本（从《期货 101》移植）
- `_data/` —— 数据基准、写作规范（本地保留，不纳入版本库）

## 构建 EPUB

```bash
python3 tools/build_epub.py
```

依赖：Python 3 + lxml。

## 说明

本书为教育材料，不构成投资建议。期权卖方风险较大，书中会反复强调；实际交易请以交易所现行规则为准。
